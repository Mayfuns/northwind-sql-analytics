# Northwind — PostgreSQL Database & Analytics Workspace

A PostgreSQL project built around the Northwind relational business dataset.

[View the supporting project](https://mayfuns.github.io/mariam-analytics-portfolio/supporting-projects.html#northwind)

## Current SQL file

[Open the uploaded Northwind SQL file](01_sql/Northwind%20SQL%20File.sql)

The uploaded file is a **complete PostgreSQL database dump/setup script**. It contains the relational schema, source data, primary keys and foreign-key relationships required to recreate the Northwind database.

It includes tables for:

- Customers
- Orders and order details
- Products and categories
- Employees and territories
- Suppliers
- Shippers
- Regions and US states

## Database skills demonstrated

- PostgreSQL schema creation
- Relational table design
- Primary-key constraints
- Foreign-key relationships
- Data loading with `INSERT` statements
- Understanding a multi-table commercial data model

## Analysis status
